# 礼宾式 MVP 人工运营手册

## 批次节奏

一个批次包含 5 个进入付费阶段的真实项目。项目中途只修阻塞性软件错误；字段、词表、预算基准和权重的变化先记入复盘，批次结束后新建配置版本。

建议看板状态：`线索 → 已访谈 → 待补资料 → 资金已承诺 → 匹配中 → 短沟通 → 已签约 → 进行中 → 验收中 → 完成/退出`。看板只放随机 ID，不放联系方式。

## 标准流程

### 1. 邀请与预筛

使用招募话术说明这是人工试验。确认项目类型、地区和风险在首轮范围内；不满足时礼貌拒绝并记录原因，不收集多余资料。

### 2. 同意与资料隔离

逐项说明 `11-participant-consent.md`。联系人进入独立加密存储，生成随机 ID；本工具和项目看板以后只使用 ID。

### 3. 需求访谈

使用 `01-demand-interview.md`，再生成 `02-demand-card.md` 和 JSON。需求方确认问题、非范围、验收、预算、决策权和数据/AI 规则。

### 4. 进入门槛

```bash
uv run mvp import demand demand.json
uv run mvp validate demand <id>
uv run mvp budget <id>
```

BLOCKER 未解决不得匹配；RED 预算必须调整；YELLOW 只在范围和报酬仍合理时书面留痕。资金承诺证据保存在外部受控位置，数据库只保存引用。

### 5. 创作者访谈与证据

使用 `03-creator-interview.md` 和 `04-creator-card.md`。至少核实一项作品或贡献；让创作者分别确认公开、匹配用和私密资料。私密底线只供过滤。

### 6. 匹配与人工复核

```bash
uv run mvp match <demand-id> --top 3
uv run mvp explain <demand-id> <creator-id>
```

先检查所有硬过滤原因，再逐项复算前三名。访谈产生的新冲突先修正资料并重新匹配。不得直接把被硬过滤者恢复进名单。

### 7. 分别确认披露

先问创作者是否愿意收到该需求，再问双方具体哪些资料可交换。发送候选说明前核对：没有身份字段、私密底线、内部标签或第三方私密反馈。

### 8. 有目的的短沟通

限定 30～45 分钟，围绕匹配说明中的未知和风险。禁止要求免费方案或样稿。会后分别记录接受/拒绝及标准原因。

### 9. 决定留痕

```bash
uv run mvp decision <demand-id> --selected <creator-id> --invited <ids...> --responses responses.json --reason <code>
```

未成交时省略 `--selected`，使用 `NO_MATCH` 或 `PARTICIPANT_CHOICE`。覆盖建议必须使用标准代码；`OTHER` 补充事实说明。

### 10. 协议和开工

用 `06-milestone-agreement.md` 在已选签署工具中形成有效版本。确认首个里程碑的资金保障后才开工。协议/付款材料不放入本数据库。

### 11. 协作、变更和验收

每周至少检查一次需求方输入、风险、交付与付款。范围增加使用 `07-scope-change.md`，交付使用 `08-delivery-acceptance.md`。口头决定当天写入共享记录。

### 12. 分开退出访谈

完成或退出后 7 天内分别执行 `09-exit-interview.md`，记录结果和发起人分环节耗时。安全反馈限制在需要知道的人范围。

```bash
uv run mvp outcome <project-id> --file outcome.json
```

### 13. 项目与批次复盘

每个项目填写 `10-retrospective.md`，只记录学习，不立即改权重。第五个项目后：

```bash
uv run mvp report <pilot-id>
```

结合反例和原始复盘作出 `继续人工验证 / 产品化一个瓶颈 / 调整方向 / 停止` 的明确选择。

## 服务标准

- 所有参与者获得同一组核心问题与相同进入门槛。
- 24 小时内确认收到关键提交；无法按期处理时说明新时间。
- 每个项目默认只邀请 1～3 人；拒绝不损害创作者后续机会。
- 只分享完成当前决定必需的资料；任何新用途重新征得同意。
- 发起人与任一方存在利益关系时，在匹配前向双方披露。

## 停止与升级

立即暂停相关项目：未授权资料披露、身份或付款主体可疑、资金承诺撤回、骚扰/歧视/威胁、明显违法或高风险专业要求、无法管理的数据安全风险。保全必要证据但停止扩大传播，按资料保护手册执行。
