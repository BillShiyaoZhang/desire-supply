# Foundations 合成制度原型规格

状态：`G0A / SYNTHETIC_PROTOTYPE`

版本：`0.1`
权威来源：仓库 `docs/foundations/`，尤其是 `readiness-and-start-decision.md`、`product-and-pilot-definition.md`、`software-delivery-charter.md` 与 `requirements-capability-registry.md`。

## 1. 目的与授权边界

本 Demo 用一组完全合成的参与者和项目，验证“受控、有报酬、可拒绝、可追溯且可救济的协作”能否被清楚表达。它是可删除的制度原型，不是生产产品。

Demo 必须在首屏持续说明：

- 只使用合成数据；
- 不建立真实身份、合同、付款或权益事实；
- 不连接真实用户、支付商、通知、文件或外部 AI；
- `G1`（生产纵切开发）和 `G2`（真人/真实数据/真实资金试点）仍为 `NO-GO`；
- 页面中的资金、协议接受、申诉和数据请求都是可撤销模拟。

## 2. 使用者与合成场景

Demo 面向评审新制度的产品、运营、工程、隐私与安全负责人。它不是供真实服务参与者使用的账户系统。

单一合成场景：一家虚构的小型公益机构，需要一名独立创作者制作一份无障碍活动信息包。项目远程完成，只涉及一名自然人创作者、一个付款方、每个合同方一名签字人，不依赖第三方场地、设备、导师、真实受益者资料或敏感个人数据。

每个 Demand 明示九类需求侧角色。资源提供者使用 `NONE / NOT APPLICABLE`，并保存理由；出资、决策、选择、验收和受益者代表不能由组织身份推断。

## 3. 可演示主旅程

主旅程对应 `PRD-P1-003..014` 和 `UC-P1-003..015` 的制度语义，但不声称实现生产能力：

1. 阅读原型边界与逐目的 Consent；
2. 查看版本化 Demand、九角色授权和创作者的最小披露资料；
3. 人工核验需求、排除项和一笔合成的项目报酬资金义务；
4. 资金为 `UNKNOWN` 时阻止匹配；核验为 `SECURED` 后生成最多三名候选；
5. 创作者可接受、拒绝、撤回或超时，拒绝不产生负面资格或排序特征；
6. 获授权选择者只能从同一次 MatchRun 中当前为 `ACCEPTED` 的候选里选择；
7. 双方对同一 AgreementVersion 明示接受后，且里程碑资金仍为 `SECURED`，才可开工；
8. 本 Demo 固定演练“仅顺延两天、不改报酬”的时间变更：生成新版本并使旧接受失效；报酬变更后的重新筹资与核验不在本 Demo 能力内；
9. 交付后载入合同验收与受益者成果确认两份分栏记录，但不模拟为两个主体分别提交的真实动作；
10. 付款依次显示 `REQUESTED / PROCESSING / UNKNOWN / PAID`；`UNKNOWN` 不推断成功或失败，也不允许盲目重试；
11. 财务事实、参与者观察、关系意愿和成果路径分开复盘，不生成全局人格分；
12. 可发起举报、最小范围临时保护和由不同人员处理的申诉；
13. 可提出访问、导出、限制或删除请求，并逐项说明第三方权利或必要保留例外；
14. 所有动作进入只追加的合成证据时间线，显示 actor、authority、版本、理由和 correlation。

## 5. 复用与隔离决定

| 现有内容 | 决定 | 理由 |
| --- | --- | --- |
| `mvp/budget.py`、`mvp/matching.py`、解释与 reason-code 测试思想 | 参考纯函数与边界，不直接导入运行 | 旧 Profile/Demand/schema、完整快照、选择与付款模型不符合新要求 |
| `platform/` 的版本/hash、同 run 接受后选择、授权和审计信封 | 复用不变量和测试案例 | 平台当前没有 Project/Payment/Rights 产品纵切或可运行产品入口 |
| 旧 repository、Outcome/report、真实试点 CLI | 不进入 Demo | 可覆盖事实、付款布尔值和推断式指标会误导新设计 |
| Community、公共金库、成员治理、AI 决策 | 明确延期 | 属于 P1 非目标，缺少真实共同体和 Gate 证据 |

原型使用独立、无持久化的状态机。刷新页面即恢复合成初始状态；任何浏览器状态都不能被描述为事实账簿。

## 6. 完成定义

- 本文每条 `DEMO-AC-*` 有具名自动化测试；
- 页面能完成一条正常旅程，并能一键载入拒绝、付款未知、申诉和数据退出反例；
- 首屏和关键资金/签字/权利组件持续显示合成/非生产边界；
- 键盘可操作、焦点可见、语义标题/按钮/状态消息完整，窄屏不丢失动作；
- 本地生产构建、领域测试和服务端渲染 smoke test 通过；
- 不含真实联系人、真实账号、生产 secret、外部请求或持久存储；
- 文档、测试名称和 UI 文案能追溯到上表的 PRD/UC/DEMO ID。
